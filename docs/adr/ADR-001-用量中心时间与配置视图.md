# ADR-001: 用量中心时间与配置视图

## 上下文

当前 usage-hub 页面直接展示起止日期、数据条数徽标、设置卡片和合并的余额/额度卡片，信息密度高但不符合“用量”插件的使用习惯。会话选择器也使用原生长下拉框，定位近期会话效率较低。

## 选项

### 时间筛选

- A：保留起止日期输入；灵活，但主页面信息负担大。
- B：只保留本年、本月、本周、昨天、今天五个预设；操作成本低，语义稳定。

### 小时趋势

- A：多日范围继续显示今天小时趋势；实现简单，但与当前筛选范围不一致。
- B：多日范围聚合小时；信息完整，但需要新增统计口径和接口能力。
- C：仅今天/昨天显示对应小时趋势，多日范围隐藏；避免误导，改动最小。

### 配置与会话视图

- 设置：页面卡片改为刷新按钮旁的侧边抽屉。
- 隐藏助手/模型：逐项开关，默认全部显示。
- 会话：选择列表按今天、昨天、更早分组，仅压缩列表，不压缩详情。
- 余额与额度：拆为两张卡片；只显示已配置来源，并只提供已配置来源的筛选。
- 侧边工具栏：独立跟随宿主当前焦点会话，展示会话级信息，不复用全局用量中心的数据入口；不展示费用。

## 决策

采用时间预设 B、小时时间处理 C，以及上述配置与会话视图方案。

## 影响

- 默认页面聚焦今天，减少无意义的全量展示。
- 多日范围只显示日趋势和其他适合多日的数据；小时图不再产生语义歧义。
- 设置不占据主内容区，隐藏项会统一影响展示数据。
- 未配置的余额/额度来源不产生空卡片或无效筛选项。
- 侧边工具栏与主页面数据语义分离：主页面看全局 ledger，侧边栏看当前会话 JSONL。
- 保留自定义日期能力不在本次范围内。
